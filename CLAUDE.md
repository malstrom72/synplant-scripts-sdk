# Synplant Scripts SDK Claude Instructions

For Synplant scripting work, use the agent package in
[`agents/synplant-script-writer/`](agents/synplant-script-writer/).

The canonical instructions are in
[`agents/synplant-script-writer/instructions.md`](agents/synplant-script-writer/instructions.md).

For `.ivg` icon or vector work, follow the native IVG2PNG authoring loop in
[`agents/synplant-script-writer/validation.md`](agents/synplant-script-writer/validation.md#static-ivg-validation);
render the IVG while designing it instead of previewing an SVG approximation with generic image
tools.
